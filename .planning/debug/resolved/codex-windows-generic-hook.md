# Debug Session: Codex Windows Generic Hook Command

## Symptoms

- expected: Windows Codex selects a Windows-compatible project hook command and the advisory KCodeRag navigation hook fails open without showing a failed pre-tool hint when the underlying tool succeeds.
- actual: Codex executes the generic `command` from `.codex/hooks.json`; its POSIX fail-open suffix is parsed by `cmd.exe`, so the hook returns 1 and Codex displays a failure before every otherwise-successful tool invocation.
- errors: `':' is not recognized`; the generic command ends with `2>/dev/null || :`. The equivalent `commandWindows` invocation returns 0 for the same input.
- timeline: Reported on 2026-08-30; the first affected release or Codex version is not yet established.
- reproduction: On Windows, invoke the installed project-level KCodeRag navigation PreToolUse hook in a Codex path that selects the generic `command`; observe `cmd.exe` interpret the POSIX suffix, return 1, and display a hook failure while the requested tool still runs successfully.
