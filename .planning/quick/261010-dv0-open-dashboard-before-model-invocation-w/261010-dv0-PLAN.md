## Scope decisions

- Latest origin/master (7353f04) contains the dashboard Skill; the initial checkout was stale. Work in isolated branch codex/dashboard-direct-open, preserving initial uncommitted changes.
- Input handling uses synchronous command hooks, never prompt/agent hooks. Only the exact dashboard command is consumed; malformed inputs and unrelated requests fail open.
- The browser-open implementation is shared, but configuration/protocols remain host-specific. No new capability or production dependency.
- OpenCode and project-only ZCode stay manual until a supported no-model path is proven; do not install global hooks to mask unsupported project behavior.
- A browser opener success means a launch request was accepted, not that the page loaded or deployment passed.
- No publish/tag. Product public entry expansion to direct dashboard handling is explicitly authorized in this chat.
