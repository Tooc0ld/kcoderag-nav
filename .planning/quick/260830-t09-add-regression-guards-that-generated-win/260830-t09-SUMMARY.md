# Windows hook popup regression guard summary

## Outcome

Generated KCodeRag Nav Windows hooks now have an executable regression contract that rejects known popup-capable or interactive launch paths. The contract covers source templates, rendered Codex/Claude commands, the decoded Node bootstrap, and the checked-in generated hook product.

## Changes

- Reject PowerShell, `cmd /k`, `start`, `pause`, `choice`, `set /p`, `Read-Host`, `$repo`, `Join-Path`, and `%CD%` in Windows hook launch paths.
- Require generated hook registrations to remain synchronous command hooks with a five-second timeout.
- Require the rendered Windows boundary to use `cmd.exe /c`, and the decoded internal launcher to use `windowsHide: true` with a five-second process timeout.
- Add known-bad examples, including the nested PowerShell `$repo`/`Join-Path` form, to prove the guard detects the reported failure pattern.
