## Trust Boundaries

| Boundary | Description |
|---|---|
| canonical/Git/npm/tar bytes → parser/generator | untrusted paths, encodings, archive entries and output cross into trusted metadata |
| trusted metadata → package/host/evidence | a false or leaking verdict can become public assurance |

## STRIDE Threat Register (ASVS L1, block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04.2-08-01 | Tampering/Elevation | path/tar traversal, links and special entries | high | mitigate | component containment, no-follow, regular-file allow-list, no extraction and adversarial tests |
| T-04.2-08-02 | Denial of service | oversized/binary/blob/member input | high | mitigate | fixed archive/blob/member/count/path/output/time limits and fail-closed decoding |
| T-04.2-08-03 | Tampering | Unicode/case/separator bypass | high | mitigate | shared NFKC/lower/separator core with synthesized variants and negative controls |
| T-04.2-08-04 | Spoofing/Information disclosure | subprocess/output injection | high | mitigate | direct argv, shell false, bounded JSON/binary protocols, no raw output reflection |
| T-04.2-08-05 | Tampering/Repudiation | scan/pack/smoke TOCTOU | high | mitigate | immutable OIDs and SHA/member-count-bound artifact reverified at every consumer |
| T-04.2-08-06 | Information disclosure | raw match, exact path, config or secret | high | mitigate | placeholder/token diagnostics, private remediation callback and secret canaries |
| T-04.2-08-07 | Tampering | external release mutation | high | mitigate | no commit/tag/publish/dist-tag/registry acquisition/refetch branch |
</threat_model>
