## Decisions Made

- Kept all exact path authority in a module-private baseline keyed by the immutable public result. A serialized or fabricated result cannot authorize verification.
- Preserved pre-existing staged work by requiring later batches to use explicit path-limited commit authority; a normal all-index commit is correctly rejected as an unexpected committed path.
- Compared unrelated stage-zero index records rather than the whole index file because an allowed explicit commit necessarily changes its own index entry while unrelated entries must remain byte-exact.
- Kept private cleanup narrow: two known regular files are removed individually, then only the proven-empty private directory is removed.
