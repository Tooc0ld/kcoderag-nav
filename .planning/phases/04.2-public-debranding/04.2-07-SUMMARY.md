## Decisions Made

- Restricted public Git subjects to full hashes or `HEAD`; both resolve to exact commit/tree IDs before enumeration, without shell parsing or reflected revision text.
- Rejected all tar extension records rather than interpreting PAX or long-name state. The current package inventory fits strict ustar and therefore has no ambiguous path authority.
- Kept exact paths process-private. CLI success, findings, and errors serialize only resolved IDs, hashes, counts, family IDs, placeholders, and opaque path tokens.
