<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| immutable subject/npm output → candidate artifact | package prediction and actual bytes are untrusted bounded subprocess results |
| artifact/workflow receipt → readiness verdict | provenance, lane and support metadata become formal assurance |
| active private lease → GitHub Actions artifact service | job-scoped runtime auth crosses an external service boundary without becoming receipt data |

## STRIDE Threat Register (ASVS L1, block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-04.2-11-01 | Tampering/Elevation | traversal/link/special package or workflow artifact | high | mitigate | private destinations, realpath containment, regular-file tar policy and safe artifact extraction |
| T-04.2-11-02 | Denial of service | oversized/binary/archive/output | high | mitigate | fixed limits, bounded JSON/output/time and fail-closed unsupported content |
| T-04.2-11-03 | Tampering | Unicode/path prediction bypass | high | mitigate | same Plan06 matcher scans dry-run paths and actual member paths/bodies |
| T-04.2-11-04 | Spoofing/Information disclosure | npm/Git/workflow/upload auth or output injection | high | mitigate | job-scoped Actions runtime auth only, fixed service origin, shell-false argv, exact JSON schemas, no raw logs/config/credentials in evidence |
| T-04.2-11-05 | Tampering/Repudiation | dry-run/pack/smoke/lane TOCTOU | high | mitigate | exact invocation counts and SHA/memberCount revalidation at every consumer/lane |
| T-04.2-11-06 | Information disclosure | match/path/secret/receipt leakage | high | mitigate | safe tokens, metadata-only receipts and canary traversal |
| T-04.2-11-07 | Tampering/Repudiation | external release mutation | high | mitigate | no commit/tag/publish/dist-tag/registry package acquisition/refetch implementation; NOT_RUN_BY_SCOPE |
</threat_model>
