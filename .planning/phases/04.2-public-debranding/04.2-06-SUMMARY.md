## Decisions Made

- Kept all family spellings out of maintained and compiled bytes by constructing aliases exclusively from numeric code points at module initialization.
- Used grapheme segmentation before NFKC folding so decomposed combining forms retain a deterministic source location without quadratic prefix normalization.
- Made the private path property non-enumerable as an additional safety boundary: callers can remediate with it, but serializing either the public result or callback payload cannot recover it.
