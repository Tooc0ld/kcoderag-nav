## Shared Patterns

### Stable secret-safe errors

**Sources:** retirement-audit.cts:143-155, pack-audit.cts:20-27, pre-release-evidence.cts:76-88.

Apply to every new maintainer boundary:

- one domain Error class with a stable code;
- optional normalized safe path only;
- a generic fallback code for unknown exceptions;
- one JSON value on stdout for success or stderr for failure;
- never echo input text, subprocess stdout/stderr, URL, header, bearer, config body, or matching alias.

### Path and object safety

**Sources:** generator/index.cts:312-344, retirement-audit.cts:213-232, pack-audit.cts:117-129 and 339-408.

- Accept only POSIX-style relative paths after one normalization boundary.
- Reject empty segments, dot/dot-dot, absolute Windows/POSIX paths, NULs, duplicates after normalization, symlinks, and special files.
- Git evidence reads immutable objects. Tar evidence parses bytes without extraction.
- Subprocesses use argument arrays with shell disabled/default direct execution, bounded output, timeouts, and Windows npm.cmd handling.

### Read/render before mutation

- Capability providers and adapters remain pure read/render layers.
- Runtime project mutation remains one applyTransaction call after all support/state/source/integrity preflights.
- Readiness is a no-write verifier. Its only temporary write is the private candidate tgz/dependency workspace, deleted after use; repository/ref state must remain identical.

### Canonical-first generation

- plugin-src and .cts are maintenance sources.
- dist, kcoderag-qa, and kcoderag-cursor are compiled/generated products.
- Run compile/generate after canonical rename; use generate --check in readiness.
- Do not hand-edit generated CJS or host Skill copies.

### Test shape

- Keep table-driven stable-code cases.
- Assert exact frozen object shapes, Object.freeze where existing contracts do, and exact check/host inventories.
- Assert negative boundaries and zero writes, not only successful renames.
- Preserve the full existing R/S structure and E01–E15 behavior tests with neutral paths/prose.
- Assert source-level absence of publish/tag/refetch branches in the new readiness module.
- Assert the same tgz hash/provenance object is observed by all five hosts and every validator.
