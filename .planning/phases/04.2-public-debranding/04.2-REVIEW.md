## Warnings

### WR-01 [WARNING]: Windows generic Codex hook leaks runtime errors to stderr

**File:** `D:\AIProgram\kcoderag-nav\src\core\project-root.cts:400`

**Issue:** `commandWindowsGeneric` appends `|| exit 0` but does not redirect the `node` process's stderr. With Node absent from `PATH`, the command correctly exits 0 and emits no stdout, but `cmd.exe` emits a 95-byte "node not found" diagnostic. This violates the project contract that advisory launchers suppress runtime failures and stderr. The regression is masked by `tests/hooks/launcher.test.cts:361-366`, which only checks that stderr is a string, and by the rendered-command assertion at line 419, which requires the unsuppressed command suffix.

**Fix:** Redirect the generic Windows command before its fail-open fallback, then restore an empty-stderr assertion for unavailable runtimes:

```ts
const commandWindowsGeneric =
  `node -e "${decoderCrossShell}" ${encoded} ${host} ${paths.state} ${paths.windowsLauncher} windows 2>nul || exit 0`;
```

In `assertUnavailableRuntimeFailsOpen`, replace the type-only check with `assert.equal(result.stderr, "")`, and update the line-419 command-shape assertion to require `2>nul`.
