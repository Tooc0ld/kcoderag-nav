## Scope Interpretation

Phase 03.1 is a behavior-preserving runtime and distribution migration, not a redesign of the
navigation policy. TypeScript modules should copy the observable contracts from the current Python
implementation while replacing its execution and installation surfaces:

- The public entry point becomes `npx kcoderag-nav@latest <command>`.
- TypeScript is maintenance source; checked-in or packaged CJS is the runtime. No `ts-node` or
  runtime compilation is allowed.
- One invocation targets one host. QA/Dev are mutually exclusive within that host; Codex, Claude
  Code, and Cursor installations may coexist in the same project.
- The target is exactly the current directory unless `--target` is given. Do not infer a Git/SVN
  root.
- Existing Python-managed installations must be verified and migrated in place before obsolete
  Python payloads are removed.
- Do not read, log, snapshot into diagnostics, or reproduce MCP credential values in tests or docs.

## Pattern Assignments

### `src/core/errors.ts`, `src/core/paths.ts`, `src/core/state.ts`, `src/core/transaction.ts`

**Primary analog:** `scripts/manage_project_install.py`

**Safe structured errors** (`scripts/manage_project_install.py:72-79`):

```python
class InstallError(RuntimeError):
    """A path-only installer error safe for command-line output."""

    def __init__(self, code: str, path: str = "") -> None:
        super().__init__(code)
        self.code = code
        self.path = path
```

Copy the contract, not the Python class shape: every expected refusal should carry only a stable
reason `code` and a normalized safe `path`. Generic failures expose only the error type/category.
Neither human nor `--json` output may include file content, URL, headers, subprocess output, or
Bearer values.

**Managed path guard** (`scripts/manage_project_install.py:230-244`):

```python
def _assert_managed_path(target: Path, relative_path: str) -> Path:
    if not (relative_path.startswith(".codex/") or relative_path.startswith(".agents/")):
        raise InstallError("outside_managed_roots", relative_path)
    candidate = target.joinpath(*relative_path.split("/"))
    current = candidate
    while current != target:
        if current.exists() and current.is_symlink():
            raise InstallError("symlink_escape", relative_path)
        current = current.parent
    resolved = candidate.resolve(strict=False)
    resolved.relative_to(target)
    return candidate
```

Generalize this to adapter-declared managed roots. The shared layer must reject absolute paths,
`..`, symlink ancestors, and any resolved path outside the normalized target. The adapter supplies
the allow-list; it must not perform unguarded writes itself.

**Drift verification before planning writes** (`scripts/manage_project_install.py:293-300`):

```python
for relative_path, expected in state["digests"].items():
    current = _read_optional(_assert_managed_path(target, relative_path))
    if current is None or _sha256(current) != expected:
        raise InstallError("managed_content_changed", relative_path)
```

Keep SHA-256 digests over bytes and verify every owned file/section before `update` or `uninstall`.
For structurally merged JSON/TOML, store enough original/managed-section state to restore unrelated
content exactly. An old state that names Python payloads must be treated as a recognized migration
schema, not as arbitrary unmanaged content.

**Whole-host transaction with rollback** (`scripts/manage_project_install.py:582-607`):

```python
paths = {relative: _assert_managed_path(target, relative) for relative in desired}
originals = {relative: _read_optional(path) for relative, path in paths.items()}
try:
    # stage every non-delete payload first
    # atomically replace/delete files; write state last
except Exception as exc:
    for relative_path, original in originals.items():
        _restore_path(paths[relative_path], original)
    raise InstallError("transaction_failed") from exc
```

The TypeScript transaction API should accept a complete desired-state plan (`Buffer | null` per
relative path), stage all bytes, commit state last, and restore all originals on any failure. A
transaction is scoped to one selected host only; rollback must not touch another host in the same
project. Report `rollback_failed` distinctly and retain a safe recovery location if restoration is
incomplete.

### `src/bin/kcoderag-nav.ts` and `src/cli/commands.ts`

**Analogs:** `scripts/manage_project_install.py:629-779,782-868` and
`scripts/manage_cursor_local_install.py:445-490`

Keep command handlers thin:

```python
target = _safe_target(target)
state = _load_state(target)
_verify_digests(target, state)
desired, _ = _desired_install(target, inputs, copy.deepcopy(state), {environment})

```

The new CLI order must be:

1. Parse command and validate Node.js 22+.
2. Resolve only `--target` or `cwd` to an absolute path; display it and confirm before mutation.
3. Select exactly one host (interactive if absent) and one environment (QA default, Dev explicit).
4. Load adapter state and detect legacy Python state.
5. Validate ownership, drift, environment conflict, and unrelated configuration before writes.
6. Build the complete plan, then execute one transaction.
7. Emit either clean human output or one stable JSON document.

`status` and `doctor` are read-only. Preserve the status vocabulary `healthy`, `not_installed`,
`drifted`, `update_available`, and `invalid`, while adding explicit Node/runtime and source issues.
With `--json`, stdout contains JSON only; diagnostics go to stderr and never get mixed into the
machine response.

The current CLI requires `--target` (`manage_project_install.py:786-796`). Do **not** copy that
detail: Phase 03.1 locks the default to `cwd`, plus a visible normalized path and confirmation.

### `src/hooks/update-check.ts`

**Analog:** `plugin-src/hooks/update_check.py`

**Foreground/cache separation** (`plugin-src/hooks/update_check.py:361-405`):


Preserve these properties:

- Foreground PreToolUse performs no network I/O.
- Missing/stale cache schedules at most one detached refresh and returns immediately.
- Cache TTL is 24 hours; session markers and locks are bounded and fail open.
- Cache and lock writes use exclusive creation/atomic replacement.
- The worker never emits output or throws through the hook boundary.

Replace only the remote/version protocol: fetch the npm registry metadata for
`kcoderag-nav`, strictly validate a bounded response, read `dist-tags.latest`, compare against the
single installed package version, and suggest `npx kcoderag-nav@latest update`. Do not retain the
GitHub raw update URL, per-environment content versions, or marketplace update commands.

For Node, the detached-worker equivalent should use a separate compiled CJS entry with ignored
stdio and `unref()`/detached process semantics. Spawn failure releases the owned lock and remains
silent. A cold `npx` network failure is a CLI acquisition failure and cannot write the project;
already installed hooks remain fully offline.

## Shared Patterns

### Validate → Plan → Commit → Roll Back

**Sources:** `scripts/manage_project_install.py:468-516,582-607` and
`scripts/manage_cursor_local_install.py:344-393`

Apply to every host install/update/uninstall. No adapter may write during detection or rendering.
All conflicts, drift, runtime checks, and legacy-state validation happen before staging. State is
committed last.

### Ownership Is Narrow and Explicit

**Sources:** `scripts/manage_project_install.py:230-300` and
`scripts/manage_cursor_local_install.py:122-146,335-341`

Adapters declare exclusive files and managed JSON/TOML sections. Unrelated host config is preserved.
Symlinks, special paths, unowned same-name content, or ambiguous sections cause a refusal rather
than overwrite/deletion.

### Secret-Safe Boundaries

**Sources:** `scripts/manage_project_install.py:158-203`, `scripts/generate_plugins.py:1-6`, and
`scripts/update_plugin.py:44-130`

Read only the minimum fields required. Error and status objects contain stable codes and safe paths.
Captured subprocess/network bodies and MCP configuration values never reach stdout, stderr, test
names, snapshots, CI artifacts, or PATTERNS/plan documentation.

### Deterministic Bytes

**Source:** `scripts/generate_plugins.py:52-54,215-235,455-463,502-578`

Normalize text to LF with one trailing newline, sort paths and keys where format permits, and compare
bytes rather than semantically reserializing generated files. Hashes prove content ownership; root
`package.json` alone supplies the release version.

### Advisory Hook Fail-Open

**Sources:** `plugin-src/hooks/grep_nudge.py:397-433` and
`plugin-src/hooks/update_check.py:299-319,361-405`

Hook exceptions are swallowed, exit is always zero, stdout is empty unless a valid protocol response
exists, and no foreground network request occurs. The hook advises; it never rejects Grep, Glob, or
Bash.

### Stable Machine Output

**Sources:** `scripts/manage_project_install.py:682-692,826-868` and
`scripts/run_host_smoke.py:41-60,349-356`

Define schema versions, enums, reason codes, and exit-code mapping centrally. `--json` output is one
JSON value on stdout. Human progress, prompts, and errors must not contaminate it.

## Migration Traps

1. **Legacy state references Python payloads.** Verify old digests first, translate state and
   originals, atomically install CJS, then remove only confirmed installer-owned Python files.
   Deleting `.py` before verification makes safe migration impossible.
2. **Current Cursor destination is wrong for the new contract.** Reuse its digest and rollback
   behavior, not `~/.cursor/plugins/local` or whole-directory deletion.
3. **Host config formats are not interchangeable.** Codex TOML/direct MCP, Claude project JSON, and
   Cursor project MCP/rule/skill need independent adapter fixtures.
4. **Environment exclusivity is per host.** A Codex QA install and Claude QA install may coexist.
   Installing Dev into one host must not uninstall or rewrite another host.
5. **The installed target is explicit.** `cwd`/`--target` is not a repository-root search. Preserve
   SVN projects and nested invocation semantics.
6. **Update protocol changes completely.** Do not leave `kcoderag-update.json`, GitHub raw fetches,
   content-suffixed versions, or marketplace update commands on the hook path.
7. **Compiled output is the product.** Test the exact packed CJS bytes and launchers, not only TS
   source imports. No Python, `ts-node`, or TypeScript compiler is allowed on the user runtime path.
8. **Node checks differ by boundary.** Mutating CLI commands hard-stop on Node <22 before writes;
   installed hooks silently fail open if Node is later unavailable; status/doctor reports it.
9. **Interactive confirmation and JSON automation conflict if mixed.** Define noninteractive
   confirmation semantics explicitly (for example a deliberate `--yes`) and never prompt in
   `--json` mode.
10. **Marketplace assets can linger accidentally.** D-03 removes marketplace as the user delivery
    path. If legacy manifests remain as generated compatibility metadata because D-07 still requires
    QA/Dev/Cursor manifest versions, they must not be installed, advertised, or used by update logic.
11. **Credentials exist in canonical inputs.** Packaging and documentation checks must prove values
    are not printed without requiring snapshots that copy the values into test output.
12. **Cross-platform atomic rename differs.** Inject rename/delete failures on Windows and POSIX;
    write state last and retain a recoverable backup if rollback itself fails.
