## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host hook payload -> CJS parser | 输入、命令字符串和 shell 结构均不可信，必须有界并 fail-open。 |
| npm Registry -> update worker/cache | 网络响应不可信且可能过大、超时或伪造 schema。 |
| Credential-bearing templates -> generated trees/logs | 生成器可复制已接受的内部配置，但不得显示内容。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-03-01 | Denial of Service | hook input/parser | medium | mitigate | 强制输入/command/segment/advisory 上限，异常 exit 0 空输出。 |
| T-03.1-03-02 | Tampering | Registry latest/cache | high | mitigate | HTTPS npm endpoint、bounded body、strict schema/semver、atomic cache、TTL/lock ownership tests。 |
| T-03.1-03-03 | Information Disclosure | generator/update logs | high | mitigate | 路径/错误码输出，synthetic network fixtures，worker ignored stdio，禁止 snapshot 真实配置值。 |
| T-03.1-03-04 | Spoofing | generated version identity | medium | mitigate | package.json 单版本源、manifest parity tests、content hash 不作为替代版本。 |
