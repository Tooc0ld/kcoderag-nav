## Decisions Made

- Current state validation is deliberately exact: a managed path omitted from ownership evidence or an unexpected path causes `invalid_state` before rendering.
- Legacy parsing is host-neutral at the core boundary; the Codex adapter supplies its precise old allowed/required path sets.
- Legacy launchers are replaced but retain their pre-Python-install originals for eventual uninstall; only state-owned, digest-matching `.py` runtime files are deleted during migration.
- `status` and `doctor` surface `legacy_migration_available` without writing, while `install`/`update` perform the replacement through the same shared state-last transaction.
