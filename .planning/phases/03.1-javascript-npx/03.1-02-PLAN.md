<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Existing host config/state -> adapter | 项目文件可能损坏、漂移或包含恶意路径/类型，必须作为不可信输入。 |
| Adapter desired-state -> transaction | adapter 只能提议受管相对路径，transaction 必须独立重新验证。 |
| Legacy originals -> diagnostics | 旧 state 可含原始配置字节，只能用于恢复，不能外泄。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-02-01 | Tampering | managed state/path | high | mitigate | SHA-256 摘要、schema/type 验证、adapter allow-list 与 transaction 二次路径检查。 |
| T-03.1-02-02 | Elevation of Privilege | symlink/root escape | high | mitigate | 拒绝 absolute/parent traversal/symlink ancestor/special file，resolved path 必须位于确认目标内。 |
| T-03.1-02-03 | Information Disclosure | status/doctor/errors | high | mitigate | 只返回 code/path/source name；不读取或打印来源值、originals 或 subprocess body。 |
| T-03.1-02-04 | Denial of Service | rollback failure | medium | mitigate | state-last、逐路径恢复、独立 rollback_failed 与安全 recovery 目录。 |
| T-03.1-02-SC | Tampering | npm install surface | high | mitigate | 仅使用 Plan 01 官方审计通过并由 lockfile 固定的开发依赖，不增加包。 |
</threat_model>
