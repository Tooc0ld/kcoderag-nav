## Decisions Made

- Claude owns only its KCodeRag MCP key and hook entry plus exclusive project files; state retains exact pre-install bytes so uninstall does not reconstruct user configuration.
- Cursor uses the fixed `kcoderag` MCP key and generated always-on Rule/skill; it deliberately does not install a hook.
- A valid legacy Cursor installation is identified by exact state keys, file and directory allow-lists, per-file/tree digests, and profile equality against the bundled QA/Dev sources without logging values.
- Cursor migration backup payloads are private temporary files; the journal contains only environment, paths, hashes, and backup identifiers, and both are removed after success or complete compensation.
- The registry contains only the three Phase 03.1 hosts. Adding a future adapter does not require transaction/state changes, but OpenCode is not added in this phase.
