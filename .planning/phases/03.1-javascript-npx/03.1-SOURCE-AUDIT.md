## Package Legitimacy Audit Gate

The plan set needs exactly two third-party development packages:

| package | version range to audit | why needed | consuming plan/task | planning status |
|---|---|---|---|---|
| `typescript` | `>=5.7.0 <7.0.0` | Compile maintained TypeScript/CTS sources into directly runnable CJS. | 03.1-01 Task 3 | Audit required before npm install/ci. |
| `@types/node` | `>=22.0.0 <23.0.0` | Type the minimum supported Node 22 built-in APIs during compilation only. | 03.1-01 Task 3 | Audit required before npm install/ci. |

Plan 01 contains a `gate="blocking-human"` checkpoint. The executor must not install either package while the legitimacy record remains absent or `[ASSUMED]/[SUS]`. No runtime dependency is planned.

## Deferred / Excluded

- OpenCode adapter and real-host evidence are deferred exactly as CONTEXT.md states; Phase 03.1 creates only the adapter seam.
- Production identity, HTTPS and credential rotation remain Phase 8 scope.
- Phase 5 hook-policy refinements are not mixed into this behavior-preserving runtime migration.

All authoritative GOAL, REQ and CONTEXT items are covered. No source item is missing.
