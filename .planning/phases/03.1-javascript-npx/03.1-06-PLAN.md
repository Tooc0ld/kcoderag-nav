<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Host CLI output -> smoke verdict | 模型自然语言与缺失执行器不可信，只有结构化事件和 stub receipt 可证明 PASS。 |
| Synthetic smoke tree -> real canonical sources | smoke 必须保持 loopback 隔离，不能把内部连接输入传给子进程/日志。 |
| Legacy deletion -> migration capability | 退役旧源码不能破坏新 installer 对已部署 state 的安全迁移。 |
| Documentation -> user shell/project | 示例命令必须匹配真实 CLI，避免误导用户写错 host/target。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-06-01 | Spoofing | smoke PASS evidence | high | mitigate | host-specific evidence truth table、structured markers、stub receipt；NOT_RUN/文本声称不算 PASS。 |
| T-03.1-06-02 | Information Disclosure | smoke/docs | high | mitigate | synthetic loopback config、safe evidence labels、canonical values 不进入 args/logs/examples。 |
| T-03.1-06-03 | Tampering | retirement deletion | high | mitigate | pre-delete full parity gate、明确 deletion allow-list、post-delete full rerun、legacy migration fixtures。 |
| T-03.1-06-04 | Repudiation | migration completion | medium | mitigate | retirement audit、pack manifest、CI matrix 和 command/docs tests 留下可重复证据。 |
