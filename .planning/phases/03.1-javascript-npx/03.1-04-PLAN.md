## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Claude/Cursor JSON -> structured merge | 项目配置可能含任意 key/type/值，只能修改明确拥有的 KCodeRag section。 |
| Host selection -> adapter transaction | 恶意或错误 host 输入不能导致多个 adapter 写入。 |
| User-level legacy source -> project doctor | 只允许读取来源名/存在性，不允许复制值或自动删除。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-04-01 | Tampering | JSON merges | high | mitigate | schema/type 检查、managed-key allow-list、original/managed digests 与写前 refusal。 |
| T-03.1-04-02 | Elevation of Privilege | cross-host path ownership | high | mitigate | host registry 精确选择一个 adapter，transaction 再校验 adapter roots，跨 host tree snapshot tests。 |
| T-03.1-04-03 | Information Disclosure | MCP/legacy diagnostics | high | mitigate | synthetic fixtures、只报告 key/source name/code/path，不记录值或原始 JSON。 |
