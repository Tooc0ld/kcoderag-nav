<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| git index/worktree -> pre-commit/release | 暂存与未暂存状态不能被 helper 隐式覆盖或错误打 tag。 |
| repository/tag -> GitHub Actions | 不可信 tag/branch 输入必须经过 version/trigger gate 才能接触发布权限。 |
| build tree -> npm tarball | 文件 allow-list 必须阻止源码、缓存、planning、Python 和敏感诊断进入包。 |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03.1-05-01 | Tampering | release tag/version | high | mitigate | clean-tree gate、semver parser、tag===package version、full gates before tag/publish。 |
| T-03.1-05-02 | Elevation of Privilege | GitHub publish job | high | mitigate | tag-only trigger、least permissions、secret only on publish step、ordinary push无发布路径。 |
| T-03.1-05-03 | Information Disclosure | CI/pack logs | high | mitigate | path-only audit、secret masking、禁止内容 dump、敏感哨兵 test。 |
| T-03.1-05-04 | Repudiation | generated release contents | medium | mitigate | deterministic generation、lockfile、version commit+annotated tag、pack manifest evidence。 |
| T-03.1-05-SC | Tampering | npm dependency/install | high | mitigate | Plan 01 官方 exact-version audit、`npm ci --ignore-scripts`、npm ls exact graph、immutable lockfile、no additional third-party packages。 |
</threat_model>
