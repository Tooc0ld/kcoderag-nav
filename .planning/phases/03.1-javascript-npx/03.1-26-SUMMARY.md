## Decisions Made

- Kept adapter-private `details` opaque; the CLI serializes only stable command, host, environment, target, status, changed-path, issue, and version metadata.
- Required JSON mutations to provide `--host` and `--yes`, but did not require `--yes` for read-only JSON status/doctor commands.
- Preserved the fixed interactive host order `codex`, `claude`, `cursor`; no OpenCode ID, entry, path, or claim was added.
- Passed the dedicated legacy authority unchanged to Cursor mutations even before a legacy path is observed, leaving actual deletion to the adapter's exact ownership preflight.
