## Decisions Made

- Used code-unit ordering rather than `localeCompare`, so path and JSON ordering cannot vary with a machine locale.
- Treated `--package all --group runtime*` as QA/Dev generation while rejecting explicit `cursor+runtime*`; this preserves a useful all-products maintainer command without inventing Cursor hook assets.
- Kept environment payloads out of result and error objects. Host projections may parse an in-memory config mechanically, but only stable codes and relative paths reach diagnostics.
- Preserved the planned migration boundary: no repository-default generation check and no legacy update-index/Python ownership in this plan.
