## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host event → dispatcher | Untrusted, host-shaped JSON enters bounded normalization and model-visible context generation. |
| dispatcher → OS cache | Stable session/root/capability facts become bounded hash-only marker state. |
| managed project → conditional fragments | State and installed files determine whether code-style and update text may be shown. |
| package bytes → host project | The exact tgz supplies the handler and adapter projection used by the tracer. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Spoofing | event normalization and epoch identity | medium | mitigate | Accept only bounded documented host/session/source fields, bind claims to host plus normalized managed root, and test unknown sources as no-reset fail-open. |
| T-05-02 | Tampering | conditional code-style fragment | high | mitigate | Verify current schema, composite digest, exact capability inventory, frozen support receipt, and every managed file digest before fragment output or claim. |
| T-05-03 | Information Disclosure | reminder and availability markers | high | mitigate | Use SHA-256 filenames and closed metadata-only records; add secret canaries and assert query/result/config/session values never appear. |
| T-05-04 | Denial of Service | malformed payloads, capacity, lock contention | medium | mitigate | Bound stdin/strings/output/files, use exclusive claims and capacity lock, retract on release failure, catch all boundary errors, and exit 0. |
| T-05-05 | Tampering | actual tgz tracer | high | mitigate | Build once, hash the actual tgz, install that path, and bind the PACKAGED observation to its SHA without accepting a launcher-only LIVE claim. |
| T-05-SC | Tampering | npm pack/exact-project package acquisition | high | mitigate | Install no new dependency; use the repository's audited package graph and exact locally hashed tgz rather than an unpinned external package. |
</threat_model>
