<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Hosted producer → package artifact consumers | An actual tgz and its digests cross job/OS boundaries. |
| Git candidate commit → protected LIVE workflow | An exact product commit identity crosses from local preparation to an authorization-controlled remote boundary. |
| Protected workflow → persistent Windows runner | Repository/workflow input reaches a machine holding installed host applications and QA credentials. |
| Native host processes → receipt serializer | Potentially sensitive host/tool output is reduced to closed metadata-only observations. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-03-01 | Elevation of Privilege | protected Windows LIVE job | critical | mitigate | Reject forks/untrusted refs before self-hosted scheduling; require protected environment and exact candidateSha; grant read-only workflow permissions. |
| T-05-03-02 | Tampering | producer artifact/candidate | high | mitigate | Bind candidate commit/tree, workflow blob, actual tgz SHA and member digest; consumers verify all identities before execution and LIVE never rebuilds. |
| T-05-03-03 | Information Disclosure | native host output/receipts | high | mitigate | Closed schema, bounded metadata allow-list, secret-shaped field/value rejection, no stdout/body persistence and a blocking secret scan. |
| T-05-03-04 | Spoofing | evidenceLevel/status | high | mitigate | Receipt validators require nativeHostProcess plus host-specific booleans for LIVE and reject direct-launcher/PACKAGED substitution. |
| T-05-03-05 | Denial of Service | persistent runner processes/cache | medium | mitigate | Per-lane project/cache isolation, bounded timeouts, process-tree teardown and finally cleanup for success/failure/interruption. |
| T-05-03-06 | Repudiation | candidate ordering | high | mitigate | Seal candidateSha only after product commit and gates; record later metadata/evidence commits separately as descendants. |
| T-05-05-SC | Tampering | npm package acquisition | high | mitigate | No new dependency/install package is introduced; use the audited lockfile and Plan 05-04 exact actual-tgz package audit. |
</threat_model>
