## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Authorized remote run → local evidence consumer | Workflow metadata and artifacts are untrusted until exact candidate/workflow/package hashes validate. |
| QA MCP/host process → closed receipt | Authenticated calls may expose queries, results, configs and credentials; only booleans/digests may cross. |
| Persistent Windows runner → five host lanes | Installed applications, workspace trust and shared machine state require strict project/cache/process isolation. |
| Candidate product commit → evidence commit | Evidence must attest the earlier immutable product SHA without changing or replacing it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-04-01 | Spoofing | remote run/ref and LIVE receipts | critical | mitigate | Verify dedicated ref, run head, workflow blob, producer tgz and every receipt against 05-CANDIDATE.json before accepting evidence. |
| T-05-04-02 | Elevation of Privilege | persistent self-hosted runner | critical | mitigate | Human-authorized protected environment only, fork/trust guard before scheduling, exact ref, read-only evidence consumption and no executor-assumed push/dispatch authority. |
| T-05-04-03 | Information Disclosure | MCP calls, host logs and docs | high | mitigate | Closed metadata schema, artifact/doc secret scan, no body capture, no config inspection and opaque credential handling. |
| T-05-04-04 | Tampering | candidate versus evidence commit | high | mitigate | Preserve candidateSha as the product commit, require evidence commit as a distinct descendant and disallow product/runtime/workflow/package changes in this plan. |
| T-05-04-05 | Repudiation | native host claims | high | mitigate | Exact per-host boolean matrix, host/version/Node/run metadata, status/stage/reasonCode and current-candidate completeness validation. |
| T-05-04-06 | Denial of Service | native processes/cache | medium | mitigate | Three isolated parallel lanes, two serialized lanes, bounded timeouts and verified process/project/cache cleanup for every terminal state. |
| T-05-04-SC | Tampering | downloaded npm artifact | high | mitigate | Download only the producer artifact already bound by candidate package SHA/member digest; no install of a new dependency or latest package resolution. |
