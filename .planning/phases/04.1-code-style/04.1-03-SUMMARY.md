## Decisions Made

- The manifest is the selection boundary; provider instances are resolved only after every requested ID validates. This makes unknown-ID refusal structurally precede contribution access.
- Providers declare only package-relative source requirements and logical section claims. They do not choose host project paths, parse host configuration, merge bytes, or call the transaction layer.
- code-style does not infer eligibility from host identity, instruction assets, or a nominal version. The existing receipt verifier must return an exact PASS row and frozen digest; otherwise the provider returns `host_version_unsupported`.
