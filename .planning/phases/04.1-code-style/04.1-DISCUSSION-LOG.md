## Skill 打包与规则内容

| 议题 | 考虑过的方案 | 用户决定 |
|------|--------------|----------|
| Skill 与 nudge 如何打包 | nav 安装 Markdown Skill + JS nudge；外部 Skill + nav nudge；仅 Markdown Skill | nav 安装纯 Markdown Skill 和独立 JS nudge；无外部 Skill、Python、SVN 或网络 |
| Skill 内容结构 | `SKILL.md` + references；单一大文件；入口引用项目文档 | `SKILL.md` 作为紧凑入口，完整规范放自包含 Markdown references |
| 安装后是否可编辑 | 完全受管；受管主文件 + override；允许直接编辑 | 完全受管，不允许直接编辑；项目差异放 `AGENTS.md` 等项目文档 |
| Skill 漂移时 Hook 行为 | 静默 fail-open；输出修复提醒；内置简版规则兜底 | 静默 fail-open；`status`/`doctor` 报 `capability_drift` |
| R01–R19/S01–S08 的迁移方式 | 改写写前规范并保留 ID；原样收录；只留高置信规则 | 改写成写前规范并保留规则号用于追溯 |
| Token 成本 | 一次短 nudge + 摘要 + 按需详情；一次加载全部详情；逐次写前写后注入 | 每会话一次短 nudge，紧凑 27 条摘要，详细规则按需读取，无逐次写后 Hook |
| 指令冲突优先级 | 用户 > 项目 > Skill；Skill > 项目；任何冲突停止 | 用户明确要求 > 项目文档 > code-style Skill，冲突时说明 |
| 写后自查 | 任务结束前有界自查；仅用户明确要求时自查 | 对实际修改区域自查一次；明确问题最小修正，需业务判断的只报告 |

**Notes:** 新 Skill 是写前决策指导，不保留旧 Python scanner/SVN 操作流程，也不宣称静态扫描通过。

## 写入触发范围

| 议题 | 考虑过的方案 | 用户决定 |
|------|--------------|----------|
| 文件类型 | 明确 C/C++/Lua 白名单；只覆盖 `.cpp/.h/.lua`；项目可配置列表 | 大小写不敏感白名单：`.c/.cc/.cpp/.cxx/.h/.hh/.hpp/.hxx/.inl/.ipp/.lua` |
| 工具调用 | 结构化写入/patch；解析常见 shell；所有源码 shell | 只处理可可靠取得目标路径的结构化 Write/Edit/MultiEdit/apply_patch 类工具 |
| 目录排除 | 内置排除；不排除；项目配置排除 | 不做目录排除 |
| Patch/rename/delete | 仅内容新增或修改；所有涉及匹配文件；只在新建时 | 内容创建/修改才触发；多文件 patch 一次；纯删除、重命名和未知路径跳过 |

**Notes:** 不解析普通 shell，避免误判、额外 token 和阻断风险。

## 首次提醒周期

| 议题 | 考虑过的方案 | 用户决定 |
|------|--------------|----------|
| 周期定义 | 每宿主会话一次；每用户消息一次；项目时间窗口 | 有稳定 ID 时每个宿主会话/线程一次 |
| 无稳定 ID 的降级 | 8 小时 marker；每次写都提示；完全静默 | 完全静默，不用 TTL 猜测任务边界 |
| Marker 位置 | OS 用户缓存；项目 cache；install state | OS 用户缓存的 `kcoderag-nav/nudges`，不污染项目 |
| Marker 异常 | 静默 fail-open；仍提示；进程内变量 | 静默 fail-open；exclusive create 保证并发最多一次输出 |

**Notes:** Marker key 只保存 host、项目边界、capability 和稳定会话 ID 的哈希，不保存 prompt、tool input 或源码路径；缓存必须有界。

## 安装与四宿主体验

| 议题 | 考虑过的方案 | 用户决定 |
|------|--------------|----------|
| Capability 选择 | 交互多选/自动化显式；默认全装；navigation 固定 | 先选一个宿主再多选；自动化重复 `--capability`；两个能力可独立安装 |
| 五命令默认语义 | 按命令安全默认；每次必填 capability；install 代表完整集合 | status/doctor 看全部，install 添加，update 默认全部已装，uninstall 必须选择 |
| 宿主能力不等价 | 明确降级；没有真实写前 Hook 就拒绝；统一称 nudge | 不允许 instruction-only/toast/阻断事件冒充写前 nudge；缺少证据就拒绝安装 |
| Cursor 旧版本 | 新版 native/旧版 instruction-only；最低版本门禁；仍仅 Rule | 设置最低已验证版本，旧版拒绝且无 Rule-only fallback |
| OpenCode 上下文能力不明 | 验证否则拒绝；instruction-only；toast | 必须验证非阻断模型上下文注入，否则拒绝 |
| Codex 文档/源码版本差异 | 最低版本门禁；假设全部支持；旧版 instruction-only | 设置最低已验证版本，旧版拒绝且不降级 |
| 版本探测 | 安装预检读取 CLI；允许跳过；由配置形态推断 | 固定宿主命令严格解析；不存在、超时、不可解析或过低均 `host_version_unsupported` |
| 多能力失败 | 整组原子；尽可能成功；逐能力事务 | 整体预检、单宿主原子事务；任一失败全部不写 |

**Notes:** Claude 使用已验证的 native pre-write；Codex/Cursor/OpenCode 的确切最低版本与 delivery evidence 留给真实宿主 fixture。版本门禁只阻止 nudge，不影响单独安装 navigation。
