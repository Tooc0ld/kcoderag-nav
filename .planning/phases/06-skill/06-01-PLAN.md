<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Skill invocation to management action | Implicit discovery may select instructions, but must not become authority for update, uninstall, or cleanup. |
| Managed state to delivery diagnostics | Local state and digests are converted into user-visible claims about installed and automatic behavior. |
| Host-version evidence to native Hook projection | A frozen receipt determines whether an automatic pre-write contribution may exist. |
| Feedback instructions to MCP tool input | User evaluation crosses into an existing remote tool and must exclude source/configuration secrets. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-06-01-01 | Elevation of Privilege | `$kcoderag-manage` implicit invocation | high | mitigate | D-04/D-10 contract tests require explicit user authorization before update/uninstall and prohibit cleanup as an inferred fallback. |
| T-06-01-02 | Spoofing | `automaticNudge=available` | high | mitigate | D-08/D-09 require the exact receipt decision plus validated native contributor files and section ownership before a positive claim. |
| T-06-01-03 | Information Disclosure | feedback and diagnostics | high | mitigate | D-05 tests reject source/configuration values, URL/Header/Bearer/token material, and captured response bodies; status remains safe metadata only. |
| T-06-01-04 | Tampering | installed Skill and metadata files | medium | mitigate | Bind every contributor file to schema-version-1 digests and preserve preflight-before-write transaction behavior. |
| T-06-01-05 | Denial of Service | pre-write advisory Hook | medium | mitigate | Retain bounded parsing, isolated catches, no foreground network work, empty failure output, and exit-zero tests. |
| T-06-01-06 | Repudiation | manual/native delivery distinction | medium | mitigate | Emit stable enum values in both JSON and human output and cover each evidence state with deterministic tests. |
