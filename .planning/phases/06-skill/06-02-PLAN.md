## Trust Boundaries

| Boundary | Description |
|---|---|
| Host/version observation to contribution rendering | Untrusted or missing version data must not grant native automatic ownership. |
| Existing installed state to renamed desired state | Old paths and originals are accepted as delete/restore authority only after full schema and digest validation. |
| Desired state to transaction | Multiple host-native files and sections cross the sole atomic write boundary. |
| Host project configuration to adapter merge | User files, JSON/JSONC/TOML sections, Rules, and Hooks must survive unrelated capability changes. |
