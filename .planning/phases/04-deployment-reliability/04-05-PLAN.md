<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User-level host state → public findings | Potentially credential-bearing config must be reduced to safe metadata. |
| Finding → native cleanup process | Only exact owned identities may become fixed argv and execute after independent authority. |
| Source scan → project transaction | All blocking findings must resolve before any desired-state render or write. |

## STRIDE Threat Register (ASVS Level 1; blocking threshold high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-05-01 | Information Disclosure | source findings | critical | mitigate | Construct findings from allow-listed metadata only and reject secret/config/process bodies from serialization. |
| T-04-05-02 | Elevation of Privilege | native cleanup runner | high | mitigate | Use fixed adapter-owned argv, dedicated authority, bounded timeout, no shell interpolation, and a post-cleanup re-scan. |
| T-04-05-03 | Tampering | pre-write source gate | high | mitigate | Complete selected-host scan before render/apply and prove zero transaction calls on conflict. |
| T-04-05-04 | Repudiation | doctor/status health | medium | mitigate | Emit deterministic stable codes, source types, scope, safe paths, severity, and truthful top-level status. |
| T-04-05-05 | Spoofing | degraded owned registration | critical | mitigate | Require the exact host/name/normalized known path/provenance/failure attribution closed shape, fixed native argv, and complete successful post-removal inventories. |
</threat_model>
