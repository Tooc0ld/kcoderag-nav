<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Session cwd → ancestor discovery | An arbitrary working directory chooses which managed project is eligible. |
| Install state → executable launcher | Project metadata selects a script that the host will execute. |
| Rendered command → Windows/POSIX shell | Quoting and path handling cross shell interpretation boundaries. |

## STRIDE Threat Register (ASVS Level 1; blocking threshold high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-04-01 | Elevation of Privilege | ancestor lookup | high | mitigate | Stop at the nearest existing state boundary, validate selected host and containment, and never fall through after parse/launcher failure. |
| T-04-04-02 | Tampering | state-to-launcher resolution | high | mitigate | Require current schema/QA ownership, regular-file launcher, and project-relative containment before invocation. |
| T-04-04-03 | Injection | generated shell command | high | mitigate | Generate fixed commands from canonical constants, quote paths per platform, and never interpolate config values or user-controlled command text. |
| T-04-04-04 | Denial of Service | Hook failure path | medium | mitigate | Bound traversal and swallow all discovery/runtime failures with empty stdout/stderr and exit 0. |
</threat_model>
