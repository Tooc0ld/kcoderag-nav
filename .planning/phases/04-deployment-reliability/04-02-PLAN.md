<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI arguments → project mutation | Untrusted flags and paths determine whether the transaction may render QA state. |
| Legacy state bytes → current desired state | Old project metadata can authorize deletion/replacement only after exact ownership and digest validation. |
| Canonical target → managed paths | A user-selected directory crosses into the sole filesystem mutation boundary. |

## STRIDE Threat Register (ASVS Level 1; blocking threshold high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02-01 | Elevation of Privilege | target selection | high | mitigate | Canonicalize once and reject roots, home, selected-host global roots, symlinks, special files, and containment escapes before adapter work. |
| T-04-02-02 | Tampering | legacy Dev migration | high | mitigate | Separate legacy decoding from current state, require exact path/digest ownership plus dedicated authority, and render one QA desired state only. |
| T-04-02-03 | Spoofing | retired Dev CLI flag | medium | mitigate | Reject the legacy selector explicitly before host detection rather than accepting or ignoring it. |
| T-04-02-04 | Information Disclosure | errors and JSON output | high | mitigate | Serialize stable codes and safe paths only; never include file bytes or configuration values. |
</threat_model>
