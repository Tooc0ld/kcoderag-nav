<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Legacy host state/config → QA desired state | Old host-specific bytes may authorize structured replacement and deletion. |
| Host adapter → transaction | Pure desired-state output is the only mutation authority. |
| Selected host → sibling host trees | One command must never mutate another host's project installation. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-03-01 | Tampering | legacy environment conversion | high | mitigate | Require exact schema/path/section/digest ownership and dedicated authority before one state-last transaction. |
| T-04-03-02 | Elevation of Privilege | cross-host mutation | high | mitigate | Keep paths and renderers inside the selected adapter and assert sibling-tree digests in cross-host tests. |
| T-04-03-03 | Information Disclosure | legacy MCP fixtures | high | mitigate | Keep credential bytes opaque and outside errors, status, receipts, and snapshots. |
| T-04-03-04 | Denial of Service | partial rollback | high | mitigate | Reuse full staging, injected failure coverage, transaction rollback, and Cursor compensation before reporting success. |
</threat_model>
