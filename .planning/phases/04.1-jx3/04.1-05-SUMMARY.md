## Decisions Made

- Stable identity is intentionally narrow: only the three documented non-empty string fields can participate in a once claim.
- Marker saturation suppresses new reminders instead of guessing which live session may be evicted.
- The current Claude receipt proves native PreToolUse delivery but not SessionEnd, so automatic production cleanup is intentionally unavailable rather than inferred.
- Integrity failures are computed before claiming once, ensuring a repaired tree can still deliver the session's first valid reminder.
